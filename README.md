# 아워 노트 한글 패치 데이터

[아워 노트 한글 패치 앱](https://github.com/ournotes-ko/patch)이 업데이트를 확인하고 받을 때 읽는 파일입니다. 직접 받을 필요는 없습니다.

- `update.json`: 최신 버전과 각 파일의 sha256·크기·주소
- `onp_master_map.bin`: 번역 맵
- `onp_images.zip`: 이미지 교체 데이터
- `onp_notice_map.bin`: 공지 번역 맵(일본 서버 공지 중 한국 서버에 같은 공지가 있는 것만, 매시간 자동 갱신)
- `SHA256SUMS.txt`: 배포 파일의 sha256(`sha256sum -c SHA256SUMS.txt`로 확인)

설치 방법은 [ournotes-ko/patch](https://github.com/ournotes-ko/patch#readme)를 보세요.
